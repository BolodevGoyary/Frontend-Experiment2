# Frontend-Experiment2: Styled Blog Post (CSS Styling)


## Objective
To learn how to apply CSS styling to an HTML document and improve webpage presentation by using selectors, typography, spacing, and colors.

## Description
This experiment demonstrates the following:

- Creating a simple blog post using HTML.
- Applying CSS styling using:
- Tag selectors
- Class selectors
- ID selectors
- Using font-family, font-size, color, background-color, margin, and padding.
- Ensuring proper readability and visual hierarchy.

## Files in this Repository
- `index.html` — The main HTML file containing the blog post.
- `style.css` — The CSS file used to style the blog post content.

## How to Run
- Clone or download this repository to your local machine.
- Open the project folder in any code editor (VS Code recommended).
- Open index.html in any web browser (Chrome, Firefox, Edge, etc.).
- The styled blog post will appear with fonts, colors, spacing, and layout applied.
